# Tracker — GitLab (`glab`)

The **GitLab** branch of `work-review` — reached when `work.tracker` (falling back to `issue.tracker`) resolves to `gitlab`. Everything a run needs whatever its tracker stays in `REFERENCE.md`.

Every write is a label move, and they mirror the implement loop's own **Tracker — GitLab (`glab`)** recipe — `glab issue update <iid> --label … --unlabel …`, against the host resolved per repo (**The forge and its host** in `REFERENCE.md`), with the assignee flags on the lease and the reconcile. Which labels those are, and which the review never writes, is **What the review writes** in `REFERENCE.md`.
