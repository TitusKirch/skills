# Tracker — GitHub (`gh`)

The **GitHub** branch of `work-review` — reached when `work.tracker` (falling back to `issue.tracker`) resolves to `github`. Everything a run needs whatever its tracker stays in `REFERENCE.md`.

Every write is a label move, and they mirror the implement loop's own **Tracker — GitHub (`gh`)** recipe — `gh issue edit <n> --add-label … --remove-label …`, with `--add-assignee` on the lease and `--remove-assignee` where the reconcile drops it. Which labels those are, and which the review never writes, is **What the review writes** in `REFERENCE.md`.
